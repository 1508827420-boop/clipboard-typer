# Clipboard Typer · 键盘输入工具

将剪贴板中的纯文字逐字输入到 Windows 输入框，适用于无法使用普通粘贴的场景。支持中文、英文、符号和 emoji，可设置固定速度、随机速度、标点停顿、分段变速、长暂停和分批续输。

A Windows clipboard-to-text-input utility built with AutoHotkey v2. Includes configurable pacing, pause/resume, batching, and optional selection-and-retyping of earlier text.

## 快速开始

需要 **Windows 10/11、64 位系统**。使用可写文件夹，首次准备运行时需要联网。

1. 下载项目 ZIP 或克隆本仓库，解压全部文件。
2. 双击 **启动输入工具.cmd**。首次启动会从 AutoHotkey 官方 GitHub 下载固定版本 2.0.30，校验 SHA-256 后解压到项目的 `runtime` 文件夹；不安装到系统，不需要管理员权限。
3. 设置窗口点击“保存并收起”。
4. 复制文字，点击目标输入框，按 **F8**，松开后开始输入。

如果网络无法下载，可从 [AutoHotkey 官方发行页](https://github.com/AutoHotkey/AutoHotkey/releases/tag/v2.0.30) 下载 `AutoHotkey_2.0.30.zip`，将其中内容解压到 `runtime`，确保存在 `runtime/AutoHotkey64.exe`。

已安装 AutoHotkey v2 的用户也可以直接运行 `输入工具.ahk`，并保持 `行为节奏.ahk` 在同一目录。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| F8 | 读取当前剪贴板，开始新任务 |
| F9 | 结束任务并清除续输位置 |
| F10 | 暂停／继续当前任务 |
| Ctrl + Alt + F8 | 打开设置；进行中的任务会结束 |

暂停后继续前，回到原输入框并保持光标位置。关闭设置只收起窗口；退出工具请在通知区域图标的右键菜单中选择“退出”。未设置开机启动。工具运行期间会占用 F8；F9、F10 只在输入任务存在时生效。

## 输入设置

基础设置包含固定间隔、随机间隔、标点停顿及换行方式。首次使用且没有本地配置时：

| 设置 | 默认值 | 可配置范围 |
| --- | --- | --- |
| 输入模式 | 随机间隔 | 固定／随机 |
| 随机间隔 | 30～120 毫秒 | 10～2000 毫秒 |
| 固定间隔 | 40 毫秒 | 10～500 毫秒 |
| 标点额外停顿 | 开启，200～600 毫秒 | 0～5000 毫秒 |
| 换行方式 | 遇到换行停止 | 停止／Shift + Enter／Enter |

Enter 或 Shift + Enter 的实际行为取决于目标程序，可能提交消息或表单。工具不会在正文末尾额外发送 Enter。遇到制表符及其他控制字符会停止，不继续输出后面的内容。

## 更多行为节奏设置

主设置中点击“更多行为节奏设置”。功能可独立启用，设置保存在本地 `设置.ini`。

| 功能 | 行为 | 默认状态 |
| --- | --- | --- |
| 分段变速 | 每 5～14 字符或空格／换行后重新选择速度系数，在基础间隔上乘以 0.65～1.7 | 开启 |
| 随机长暂停 | 暂停间隔在所设平均字符数的 75%～125% 内随机取值；默认平均每 100 字符暂停 2.5～6 秒 | 开启 |
| 平均速度限制 | 限制本次累计的输入及高级修订动作速度；每次删字、重输字符均计入，人工暂停时间不计入，自动长暂停计入 | 开启，240 字符／分钟 |
| 分批输入 | 每批结束后暂停，等待用户按 F10 继续；默认每批 300 字符 | 关闭 |
| 前文回选重输 | 在已输入末尾前 3～12 个字符处选中一个中英文字符，原样重输后返回末尾；默认平均每 80 字符尝试一次 | 关闭 |

基础间隔、分段变速、标点停顿、长暂停及速度上限会叠加，最终间隔可以长于基础随机范围。Windows 定时器调度也会带来偏差。速度单位为**字符／分钟**，不是英文单词／分钟；中文每字计一字符。

前文回选重输会移动光标，相关后缀含 emoji、组合字符、换行或其他不支持字符时会跳过。请先用短文验证目标编辑器，富文本、自动补全和特殊控件可能改变光标行为。此功能原样重输，不改写正文；分批休息不替目标网站创建新会话。

## 可选高级句段修订

在“更多行为节奏设置”中点击“高级句段修订（可选）”。旧版单字回选重输完整保留；开启高级版时，本任务只执行高级版，关闭后恢复旧版开关的行为。

高级版可选择两种修订方式：

- **草稿句 → 定稿句**：预先填写“草稿片段 => 定稿片段”，先输出草稿，回看时逐字删除草稿，再逐字输入定稿。
- **定稿删除后原样重输**：无需填写配对，直接从剪贴板纯文字中自动选取符合长度范围的句段。优先选完整句，过长的句子随机选一个设定长度的连续词／字符片段；过短的句子跳过。先逐字删除，再逐字输入同一段文字。

两种方式均沿用主设置的固定／随机间隔、分段变速、标点停顿、长暂停和速度上限；删除与重输每个字符均经过定时调度，**不整段瞬间替换，也不执行粘贴**。速度上限和长暂停间隔会计入高级版删除及重输动作。旧版单字回选重输保留原有行为。

草稿模式每行一组，例如：

```text
This was a rough sentence. => This is the clear final sentence.
```

两种模式的剪贴板都放**完整定稿**。工具不会自动生成、改写或上传句子。草稿模式中，配置的片段不能包含换行或 `=>`，同一定稿片段不能重复配置。重输模式中，若没有满足长度要求的片段，只执行正常逐字输入。

- 默认两次修订的目标间隔为 **25～45 个单位**。
- 从待修订片段的起点回看 **20～30 个单位**，在范围内选择已经完整输入的候选片段。
- 定稿片段长度为 **5～10 个单位**；长度范围在应用时检查。
- 回看前随机停顿 **700～1800 毫秒**，期间 F9、F10 仍可使用。
- 默认按英文词计数（连续字母／数字及内部撇号为一个词），中文可选择“非空白字符”。上述三个范围都可调整。

这些范围是回看调度目标：只有候选片段已输入且位置满足条件时才执行，不承诺每次都在指定间隔发生。草稿模式的未修订片段在结尾补完，以恢复定稿；重输模式按间隔选择候选，不对每句话都执行重输，短文未发生周期修订时结尾最多补一次。成功完成后的正文应与剪贴板定稿一致；**F9 中止、遇到不支持字符或编辑器不兼容时，可能留下草稿或尚未重输完整的片段**，请检查正文。删除和重输途中均可 F10 暂停／继续，F9 结束后不再自动补写。

高级版默认关闭，方式、开关、句段与范围仅对当前进程有效，**不写入磁盘**，重启后重新选择。Windows 原生 Edit 输入框会在每步删改前核对文本与光标，检测到手动改动时停止；其他编辑器仅对可预测的 ASCII／常用汉字光标移动尝试按键删除和逐字文本输入，尚未验证浏览器、富文本和远程桌面。请不要在删改途中手动移动光标或编辑正文。

## 兼容性与本地数据

- 工具输入纯文字，不输入图片、格式或富文本，不执行 Ctrl + V 粘贴。
- 标准 Windows Edit／RichEdit 控件使用定向字符消息及同步选区操作；其他控件使用 AutoHotkey 文本／按键发送。Unicode 文本事件不等同于物理键盘扫描码。
- 正在输入时切换窗口会停止；普通桌面控件切换输入框也会停止。网页内不同输入框可能共用一个控件，无法保证识别网页内的焦点变化。
- 非标准控件中，窗口切换瞬间已经发送的按键可能仍在处理。需要切换窗口时先按 F10 暂停。
- 部分远程桌面、虚拟机、游戏或特殊控件可能不接受输入；目标应用以管理员身份运行时，普通权限工具也可能无法输入。
- 运行工具不上传或保存剪贴板正文，不改写剪贴板。仅在 F8 开始时读取文字，暂停任务内容仅保存在内存中，退出后不保留。
- 首次准备运行时会访问 GitHub 下载官方 ZIP；日常输入无需网络。`设置.ini`、验收输出及运行时均在 `.gitignore` 中排除。

输入兼容性、网站的行为评分和会话划分由目标程序决定，本项目不承诺评分结果或证明文字的创作来源。

## 验证与开发

在具备真实交互桌面的 Windows 上运行：

```powershell
.\启动输入工具.cmd --test
```

测试会短暂创建自己的输入框并切换测试窗口焦点，结束后恢复原剪贴板，结果写入 `验收结果.txt`，失败返回非零退出码。请避免在测试时操作其他窗口；不支持无桌面环境。

首版在 Windows 独立 Edit 输入框及 AutoHotkey 2.0.30 上通过 21 项检查，包括随机范围、标点与长暂停、累计速度限制、中英文／emoji、暂停续输、分批、前文重输正文一致性和焦点切换。浏览器编辑器、目标网站评分及远程桌面尚未验证；没有配置 CI，不将本机验收作为全平台兼容承诺。

v0.2.0 在相同环境中通过 29 项检查，新增高级版英文／中文计数、配置检查、修订前停顿、暂停续输、不同长度和重复片段的最终正文一致性验证。

v0.3.0 在相同环境中通过 38 项检查；分别记录了草稿和定稿两种模式的实际文本变化及时间间隔，验证逐字删除／重输、中途暂停续输与结束后不再删改。

| 文件 | 作用 |
| --- | --- |
| `输入工具.ahk` | 主程序、基础设置、输入及焦点检查 |
| `行为节奏.ahk` | 分段速度、长暂停、限速、分批、回选重输与高级设置 |
| `高级修订.ahk` | 可选草稿／定稿句段、计数与回看替换 |
| `验收.ahk` | 桌面集成验收 |
| `启动输入工具.cmd` | 启动入口及测试入口 |
| `prepare-runtime.ps1` | 从官方源下载并校验固定版本运行时 |
